# 🏛️ Country Holidays Hotels & Resorts (CHHR)

> A modern, editorial luxury hospitality platform and architectural showcase for boutique sanctuaries, signature suites, celebrations, and executive CMS lead management.

---

## 🌟 Key Features

- **Editorial Luxury Design System**: Custom-crafted HSL color tokens (`#FF1F02` brand red accent, `#FAFDF2` luxury ivory, `#181824` dark backdrop).
- **Interactive Cartoon Mascot Login**: Animated character that tracks input text and covers its eyes when typing passwords.
- **Dynamic Accommodations CMS**: MongoDB Atlas integrated suite manager (`02 — ACCOMMODATION`).
- **Celebrations Lead Capture CRM**: Instant event brief submission desk for destination weddings and banquets.
- **Cinematic Lightbox Gallery**: Masonry grid with full-screen viewer and categorized photography.
- **Executive Control Center (CMS)**: Fully featured administrative portal (`/admin`) with JWT auth guards, real-time telemetry, and inventory management.
- **MongoDB Atlas Cloud Integration**: Real-time database cluster synchronization with DNS resolution fallback.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Framer Motion, Lucide Icons, React Router v6, Axios
- **Backend**: Node.js, Express, MongoDB Atlas, Mongoose, JWT, Bcrypt, Helmet, CORS, Morgan

## 🚀 Getting Started

### 1. Prerequisites
- **Node.js** (v18 or newer recommended)
- **npm** (v9 or newer)

### 2. Installation

```bash
# Clone the repository
git clone https://github.com/sunnysharma41918-web/RESORTS_WEB.git
cd RESORTS_WEB

# Install client dependencies
cd client
npm install

# Install server dependencies
cd ../server
npm install
```

### 3. Running Locally

```bash
# Terminal 1: Start Client
cd client
npm run dev

# Terminal 2: Start Backend Server
cd server
npm start
```
